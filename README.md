# reljabulajic.com

The source for [reljabulajic.com](https://reljabulajic.com), my production portfolio as a senior AI systems and prompt engineer who independently architects and ships complete products.

## What this repository demonstrates

- A production Next.js 16 App Router site with React 19 and TypeScript
- 30 structured product case studies plus five deep AI-system architecture studies
- A dedicated AI-systems portfolio covering agent orchestration, production prompt engineering, Python backends, evaluations, voice AI and human-in-the-loop automation
- System-specific animated architecture scenes that make routing, policy and agent behavior inspectable
- Route-specific metadata and generated Open Graph assets
- A responsive design system built with Tailwind CSS 4
- Client-side motion with reduced-motion handling and a canvas flow field
- Static generation across the complete public portfolio

## Featured production work

- **Vael:** SwiftUI, Next.js and Chrome extension surfaces over a shared Supabase backend with 33 Edge Functions and 124 migrations
- **DeepLead:** Next.js 16, Supabase and Claude Agent SDK with specialized agent workflows, evaluation gates and 40 automated tests
- **LaunchPilot:** custom agent orchestration, multi-model routing, social integrations and scheduled Vercel jobs
- **Paycontrol:** complete FastAPI and PostgreSQL backend with Plaid banking, encrypted tokens, transaction sync, a spending-rules engine, 50 endpoints and 36 automated tests
- **VoiceVault:** voice-first agent system with 46 API routes, 44 AI and voice modules, conversational memory and tool-routed actions
- **SupportAgent:** multi-app customer support agent with grounded responses, confidence routing, explicit escalation policy and a realtime native operator queue
- **Trace:** privacy-aware SwiftUI and FastAPI public-web research system
- **DispatcherPro:** real-time React and Firebase operations system shipped for a US trucking client

The core product and client repositories remain private. Architecture facts shown in this portfolio are derived directly from the underlying codebases, migrations, routes and test suites.
